# 🌦️ SkyCast - Advanced Weather Forecast App

SkyCast is a modern and responsive weather forecast web application built using **HTML, CSS, and JavaScript**.  
It provides real-time weather updates, beautiful animated UI, dynamic backgrounds, voice search, and live weather forecasting.

This project was created as a frontend practice project for internship preparation and real-world API integration learning.



---

# 🚀 Features

✅ Real-Time Weather Data  
✅ 5-Day Forecast  
✅ Current Location Weather  
✅ Voice Search 🎤  
✅ Dynamic Backgrounds According to Weather  
✅ Animated Clouds ☁️  
✅ Day / Night Theme ☀️🌙  
✅ Rotating Sun & Moon Animation  
✅ Glassmorphism UI  
✅ Responsive Design  
✅ Live Time & Date  
✅ Real Weather Images  
✅ Auto Weather Refresh  
✅ Smooth User Experience  


---

# 🛠️ Technologies Used

- HTML5

- JavaScript (Vanilla JS)
- OpenWeather API
- Fetch API
- Geolocation API
- Speech Recognition API
