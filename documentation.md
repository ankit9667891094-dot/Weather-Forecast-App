# 🌦️ SkyCast Weather Forecast Web Application

---

# 📌 Project Overview

SkyCast is an advanced weather forecast web application developed using HTML, CSS, and JavaScript.

The application provides real-time weather updates using the OpenWeather API and includes a modern responsive user interface with animations, dynamic backgrounds, voice search, and weather forecasting.

This project was created for frontend development practice and internship portfolio purposes.

---

# 🎯 Objectives

The main objectives of this project are:

- To learn API integration using JavaScript
- To create a modern responsive web application
- To understand real-time data fetching
- To improve frontend development skills
- To create an internship-ready project

---

# 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of web pages |
| CSS3 | Styling and animations |
| JavaScript | Functionality and API integration |
| OpenWeather API | Real-time weather data |
| Fetch API | Fetching API data |
| Geolocation API | Current location weather |
| Speech Recognition API | Voice search feature |

---

# ✨ Features

## ✅ Real-Time Weather Data
Displays:
- Temperature
- Humidity
- Wind Speed
- Pressure
- Weather Description

---

## ✅ 5-Day Forecast
Shows future weather forecast for upcoming days.

---

## ✅ Dynamic Backgrounds
Background images automatically change according to:
- Clear weather
- Rain
- Clouds
- Snow
- Thunderstorm

---

## ✅ Voice Search
Users can search weather using microphone input.

---

## ✅ Current Location Weather
Fetches weather using browser geolocation.

---

## ✅ Day & Night Theme
Sun and moon theme changes automatically according to current time.

---

## ✅ Animated UI
Includes:
- Moving clouds
- Rotating sun
- Glassmorphism design
- Smooth hover effects

---

## ✅ Responsive Design
The application works properly on:
- Desktop
- Tablet
- Mobile devices
